# BluePrints — Certificate Courses Website

A modern, responsive certificate-course website for **The BluePrints**, designed to showcase professional and legal drafting courses and make course enquiries simple.

## Live Website
https://blueprintstech.netlify.app/

## Features
- Responsive design
- Light / dark mode
- Animated hero carousel
- Course and certificate gallery
- Certificate image preview
- WhatsApp enquiry
- Email enquiry
- Phone call actions
- Smooth scrolling and animations

## Tech Stack
HTML5 · Tailwind CSS · JavaScript · Font Awesome · Material Icons
